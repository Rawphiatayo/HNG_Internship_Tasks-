# European Pharmacy Sales and Profitability Report

This folder contains the pharmacy sales and profitability analysis deliverables.

## Contents
- `Pharmacy_Sales_Analysis.xlsm` - macro-enabled Excel report with dashboard and calculations.
- `Pharmacy_Sales_Analysis.xlsx` - regular Excel workbook version.
- `Pharmacy_Sales_Analysis_Real.xlsx` - final or real dataset workbook.
- `European_Pharmacy_Analysis.xlsx` - supplementary data analysis workbook.
- `European Pharmacy Sales and Profitability Dataset.xlsx` - the main dataset used for analysis.
- Wireframes and dashboards in image files such as `Dashboard_Page1.png`, `Dashboard_Page2.png`, `Dashboard_Page3.png`, and `European_Pharmacy_Wireframe_ppt.png`.
- Design and brief documents like `Analysis_Requirements.docx`, `Excel_Dashboard_Report_Brief.docx`, and `Wireframe_ppt.pptx`.

## Notes
- Open Excel workbooks with Microsoft Excel to view the data and dashboards.
- Use the images and design files for review of the report layout and visual strategy.
