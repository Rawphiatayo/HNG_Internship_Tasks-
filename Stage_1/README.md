# Stage 1

This folder contains the Stage 1 movie rating analysis project and supporting documentation.

## Contents
- `stage_1_python_task.ipynb` - Jupyter notebook with the analysis code and results.
- `cleaned_merged_movie_dataset.csv`, `links.csv`, `movies.csv`, `ratings.csv`, `tags.csv` - movie dataset files used in the analysis.
- `Movie_Rating_Python_Report.pdf` - final report output.
- `Stage1_Report_RofiatMuhammad_Python_Movie_Project.docx` and `.pdf` - project report documents.
- Project question file: `Stage_1_Questions.docx`.
- Submission folder: `Stage1_MuhammadRofiat_Submission_delivarables/`.

## Notes
- Use the notebook and dataset files together to reproduce the analysis.
- The PDF and Word reports summarize findings and visualizations.
