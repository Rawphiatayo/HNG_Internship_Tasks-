# Pizza Sales Report

This folder contains the pizza sales dataset, report file, and a SQL query for analysis.

## Contents
- `pizza_sales.csv` - sales dataset for pizza orders.
- `pizza_sales_excel_file.xlsx` - Excel workbook version of the pizza sales data.
- `Pizza_Sales_Report.pbix` - Power BI report file.
- `SQL_query_pizza_sales.sql` - SQL query used to analyze the pizza sales data.
- `pizza-slice.png` and `Logistics dashboard.jpeg` - visual assets used in the report.

## Notes
- Use the SQL file and datasets together for analysis in databases or query tools.
- Open the Power BI file in Power BI Desktop to review the interactive dashboard.
