# Stage 2

This folder contains Stage 2 data analysis tasks, including movie rating visuals, task workspaces, and election analysis outputs.

## Contents
- `Stage2_Task_1/` - SQL task folder with raw datasets and query solutions.
- `Stage2_Task_2/` - election analysis folder with maps, cleaned CSV files, and notebooks.
- Analysis images such as `Average Rating vs Movie Age.png`, `Distribution of ratings.png`, and `Top 10 rated movies.png`.
- `Stage2_Task_1/` includes SQL files and raw datasets for rides, drivers, payments, and riders.
- `Stage2_Task_2/` includes election analysis notebooks, map outputs, and cleaned datasets.

## Notes
- Open the notebooks in `Stage2_Task_2/` to view election analysis and visualizations.
- Use the SQL folder files in `Stage2_Task_1/` to inspect query answers and raw dataset transformations.
