# Stage 0

This folder contains the Stage 0 project artifacts, including the pharmacy sales dashboard design, wireframes, and report deliverables.

## Contents
- `Pharmacy_Sales_Analysis.xlsm` and `Pharmacy_Sales_Analysis.xlsx` - Excel report files.
- `European Pharmacy Sales and Profitability Dataset.xlsx` - dataset used for analysis.
- Design assets such as `Dashboard_Page1.png`, `Dashboard_Page2.png`, `Dashboard_Page3.png`, `First_Wireframe.png`, and `White_Pharmacy_logo.webp`.
- Planning documents like `Analysis_Requirements.docx`, `Excel_Dashboard_Report_Brief.docx`, `Stage0_question.docx`, and `Wireframe_ppt.pptx`.
- Presentation and PDF outputs: `Stage0_RofiatMuhammad_SalesDashboard.pdf` and `Stage0_RofiatMuhammad_SalesDashboard.pptx`.

## Notes
- This folder documents the early-stage project work and dashboard design process.
- Open the Excel and presentation files to review the completed analysis and final recommendations.
