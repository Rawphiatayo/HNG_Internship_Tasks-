# Stage 3

This folder contains data cleaning, merging, and analysis work for FIFA data and other tasks.

## Contents
- `clean_fifa_tables.ipynb.py` and `merge_fifa_tables.ipynb.py` - Python scripts for data cleaning and merging.
- `webscrapping.ipynb` - notebook for web scraping tasks.
- `Task_1_group/` - task-specific dataset folder with cleaned tables and original CSVs.
- `Task_2/` - bank and SEO analysis dataset folder.

## Notes
- Open the `.ipynb.py` scripts and notebooks with an editor that supports Python or Jupyter.
- Review `Task_1_group/` for FIFA data cleaning outputs and `Task_2/` for SEO/banking analysis data.
